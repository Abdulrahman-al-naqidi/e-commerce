# BeeSound - Electronics Store Front End

![HTML](https://img.shields.io/badge/HTML-5-E34F26?logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS-3-1572B6?logo=css3&logoColor=white)

A multi-page front end for an online electronics store, built with HTML, CSS and vanilla JavaScript.

**Live Demo:** https://e-commerce-dun-sigma-66.vercel.app

## Features

- Home page with featured and new-arrival product sections
- Product detail page
- Shopping cart and checkout pages
- Responsive navigation and layout

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks)

## Run Locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deployment

Deployed on Vercel: https://e-commerce-dun-sigma-66.vercel.app
